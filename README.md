# My Delivery — iPhone PWA

A personal delivery-order tracker. It is not affiliated with Amazon or any delivery company.

## What's included
- Add, edit, delete orders
- Customer name, phone, order ID, address, order amount, COD amount, notes
- Status: Pending, Picked Up, Out for Delivery, Delivered
- Basic totals for delivered order value and pending COD
- Data stored locally in the browser on this device
- PWA manifest, offline cache, and app icons

## Install on iPhone for free
1. Publish these files to a free HTTPS static host (for example, a GitHub Pages repository).
2. Open the published website in **Safari** on your iPhone.
3. Tap **Share** → **Add to Home Screen** → **Add**.

## Important
- The app stores order data in local browser storage. It does not sync between devices.
- Do not enter sensitive customer information unless you have permission and a legitimate reason.
- Export your orders periodically from Settings.
- If Safari website data is cleared, locally saved orders may be lost.
- This is a personal tracker, not an official Amazon app.
